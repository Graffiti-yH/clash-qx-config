# 维护说明

## 节点组原则

| 策略组 | 节点范围 | 自动跳转范围 |
|---|---|---|
| AI—自动—美国 | 仅美国节点 | 仅美国节点之间 |
| AI—手动—美国 | 仅美国节点 | 不自动跳转 |
| 社交—自动—日本 | 仅日本节点 | 仅日本节点之间 |
| 社交—手动—日本 | 仅日本节点 | 不自动跳转 |
| 流媒体—自动—港澳台 | 香港/台湾节点 | 仅香港/台湾之间 |
| 流媒体—手动—港澳台 | 香港/台湾节点 | 不自动跳转 |
| 其他海外—自动 | 全部国家节点 | 全部国家节点 |
| 其他海外—手动 | 全部国家节点 | 不自动跳转 |

如果“自动选择”发生节点切换，只会在该策略组允许的国家范围内切换，不会跨到其他国家。

## 订阅节点命名

建议订阅服务中的节点名称带有明确国家标记，例如：

```text
美国｜洛杉矶｜01
日本｜东京｜01
香港｜01
台湾｜01
```

配置模板依靠节点名称筛选国家。如果订阅商使用其他命名方式，需要修改 `filter` 正则表达式。

## 公开仓库安全

不能提交：

- 订阅 URL
- VLESS UUID
- Trojan 密码
- API Key
- GitHub Token
- Cookie

配置模板中的 `订阅节点` 只是占位名称，需要在本地配置中关联真实订阅。
