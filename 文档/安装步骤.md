# 安装步骤

## 一、准备

1. 从 App Store 安装 Clash for Apple Platforms。
2. 在 iPhone 安装 Clash；Quantumult X 仅作为备用客户端。
3. Mac 安装 Clash；Otty 和系统终端都由 Mac Clash 的 TUN 接管。
4. 准备订阅服务，但不要把订阅链接发到公开仓库或聊天中。

## 二、Clash Mac

1. 打开 Clash，添加订阅。
2. 导入 `Clash/配置模板.yaml`，或将模板中的规则提供商加入现有配置。
3. 在本地把 `订阅节点` 替换为真实订阅名称/来源。
4. 开启 TUN/系统代理。
5. 先测试“其他海外—手动”，再测试分类规则。
6. 终端、Otty、Git、API 与桌面客户端默认由 Clash 接管；遇到特殊工具再增加进程规则。

## 三、Clash iPhone

1. 添加同一订阅。
2. 导入配置模板或导入六个 Clash 规则链接。
3. 选择对应策略组：
   - AI：`AI—手动—美国` 或 `AI—自动—美国`
   - 社交：`社交—手动—日本` 或 `社交—自动—日本`
   - YouTube：`流媒体—手动—港澳台` 或 `流媒体—自动—港澳台`
   - 其他海外：`其他海外—手动` 或 `其他海外—自动`
4. 按需开启 Clash VPN。

## 四、Quantumult X 备用

1. 先关闭 iPhone Clash VPN。
2. 在 Quantumult X 内添加同一订阅。
3. 导入 `Quantumult X/配置模板.conf` 的规则远程链接。
4. 按订阅中的实际节点名称替换模板内的示例节点。
5. 默认不要启用 MitM；只有明确需要 Rewrite 时再单独配置。

## 五、首次验证顺序

1. 局域网 NAS/打印机是否可用。
2. 微信、QQ、支付宝、银行和运营商 App 是否可用。
3. 国内网站是否直连。
4. ChatGPT、Gemini、Claude、Codex、Grok 是否使用美国节点。
5. X、Instagram 是否使用日本节点。
6. YouTube 是否可在香港/台湾节点间手动切换。
7. 关闭所有代理节点后，海外流量是否阻断。
