# 故障排查

## AI 显示地区限制

1. 确认策略组是美国节点，而不是“其他海外”。
2. 关闭并重新打开对应 App。
3. 检查节点出口 IP 的国家和 ASN。
4. 换一个美国节点；不要直接切换到其他国家绕过规则。
5. 清理浏览器 Cookie 或使用无痕窗口重试。

## X / Instagram 无法使用

1. 确认使用“社交—日本”策略组。
2. 检查是否有域名命中记录。
3. 更换日本节点。
4. 暂时关闭广告拦截规则测试，确认不是误伤。

## YouTube 播放异常

1. 在“流媒体—手动—港澳台”中选择香港或台湾节点。
2. 重新打开视频。
3. 检查 `googlevideo.com` 是否命中流媒体规则。
4. 若地区内容不同，记住 YouTube 可能根据出口 IP、账号和 Cookie 综合判断。

## 国内 App 异常

1. 确认命中中国大陆直连规则。
2. 确认广告拦截规则没有拦截业务域名。
3. 将具体域名加入对应直连白名单。
4. 银行、支付、微信、QQ 和运营商业务优先保证直连。

## 局域网设备异常

1. 确认局域网 IP 在 `192.168.0.0/16`、`10.0.0.0/8` 或 `172.16.0.0/12` 范围内。
2. 确认 `.local` / `.lan` 域名走直连。
3. 检查系统是否启用了“限制本地网络”权限。
4. 不要把局域网设备交给海外代理策略。

## DNS 异常

1. 先保持 `redir-host`，不要立即切换 fake-ip。
2. 检查系统 DNS 和 Clash DNS 是否同时生效。
3. 如果海外域名失败，依次测试 1.1.1.1、8.8.8.8 或订阅商推荐 DNS。
4. 如果国内 App 失败，优先检查国内 DNS 分流和白名单。
5. 检查 DNS 泄漏时，应在 Clash 开启状态下测试。

## 节点全部不可用

这是预期的故障保护行为：海外流量应被阻断，而不是回退直连。先检查订阅更新、节点有效期和策略组筛选条件。
