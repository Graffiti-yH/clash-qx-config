# 本地订阅转换器

## 启动

在终端执行：

```bash
cd ~/clash-qx-config
python3 工具/本地订阅转换器.py
```

浏览器打开：

```text
http://127.0.0.1:8765
```

默认程序只绑定 `127.0.0.1`，不会开放到局域网或公网；不会把订阅地址写入 GitHub，也不会保存到磁盘。关闭终端后，内存中的转换结果会消失。

如果希望让同一局域网的手机直接订阅，在 Mac 上使用：

```bash
python3 工具/本地订阅转换器.py --局域网 --地址 192.168.1.100
```

把 `192.168.1.100` 换成 Mac 当前局域网 IP。网页生成结果会显示一个临时局域网订阅地址，例如：

```text
http://192.168.1.100:8765/sub/临时令牌/clash.yaml
```

将这个地址直接添加到手机 Clash 的远程配置/订阅中。手机和 Mac 必须连接同一个局域网，且运行转换器的终端不能关闭。令牌只保存在内存中，每次重新生成会使上一次地址失效。

## 生成的文件

- `覆写节点.yaml`：`proxies:` 节点片段，包含服务商返回的全部可识别节点。
- `全部协议链接.txt`：输出 SS、VMess、Trojan 等对应协议链接。

服务商节点如果是 Trojan，不能直接改写成 SS 或 VMess；强行转换会导致无法连接。因此程序保留为 `trojan://`，不会排除 Trojan。推荐使用 `覆写节点.yaml` 或“全部协议链接.txt”。

网页中的局域网 `.../sub/.../clash.yaml` 是完整 Clash 配置订阅，会同时包含节点和本仓库分流规则；手机无需再导入本地文件。网页同时提供 `.../sub/.../links.txt`，可填写到 Quantumult X 的 `[server_remote]`。

## 导入纯分流配置和节点

1. 在 Clash 导入 GitHub 的纯分流配置：

   ```text
   https://raw.githubusercontent.com/Graffiti-yH/clash-qx-config/main/Clash/%E7%BA%AF%E5%88%86%E6%B5%81%E9%85%8D%E7%BD%AE.yaml
   ```

2. 启用该配置。
3. 打开 Hako 的：

   ```text
   配置 → 纯分流配置 → 覆写
   ```

4. 将网页下载的 `覆写节点.yaml` 内容加入覆写内容并保存。
5. 由于纯分流配置的策略组使用 `include-all: true`，加入的节点会自动进入对应策略组。

如果 Hako 的“覆写”界面不接受完整 `proxies:` 片段，也可以在“代理提供商”中添加一个本地节点文件；不要把订阅 URL 放入公开仓库。
